# GB-11 — 국가·지역별 성장지표·우수 성장기지 추천·본부 자동보고

버전: v3.27.0

## 목적
GB-10의 HQ → 국가관리자 → 지역관리자 권한 범위를 그대로 사용해 각 운영자가 자기 범위 안의 성장기지 성과만 분석한다.

## 분석 기준
최근 7일 기준으로 다음을 함께 본다.
- 참여율: 활성 회원 중 실제 활동 회원 비율
- 활동 증가율: 최근 7일과 직전 7일 비교
- 저장된 LEVEL 운영품질 점수
- 승인대기 상태
- 최근 활동 지속성

운영점수는 100점 기준이며 단순 누적 SPARK나 전체 회원 수를 직접 우대하지 않는다.

## 우수 후보
운영점수 70점 이상이며 지원 필요 신호가 없는 성장기지를 후보로 표시한다.

## 지원 필요
다음 중 하나면 지원 필요 신호를 표시한다.
- 최근 7일 활동 없음
- 승인대기 10건 초과
- 최근 7일 참여율 15% 미만

## 권한
RPC `spark_scoped_growth_insights()`는 authenticated 전용이며 함수 내부에서 HQ 관리자 또는 `spark_network_admin_scopes`의 활성 국가/지역 관리자 여부를 다시 검사한다. anon/public 실행권한은 제거했다.

## 화면
`network-insights.html`
- 자동 운영보고 문장
- 담당 국가/지역/센터/회원/활동 요약
- 우수 성장기지 후보
- 지원 필요 성장기지
- 국가·지역별 평균 운영점수와 참여율

## 검증
HQ JWT 컨텍스트로 실제 호출을 확인했다. 현재 데이터 기준 KR / 울산 1개 성장기지, 활성 회원 69명, 최근 7일 활동 57건, 실제 참여자 9명, 참여율 13%, 운영점수 45, 우수 후보 0, 지원 필요 1로 계산되었다.

신규 운영데이터나 테스트용 성장활동은 생성하지 않았다. Supabase Security Advisor도 실행했으며 기존 프로젝트 전반의 SECURITY DEFINER/RLS 관련 경고는 별도 보안 정비 트랙으로 유지한다.
