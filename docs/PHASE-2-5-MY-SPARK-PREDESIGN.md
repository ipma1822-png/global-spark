# GLOBAL SPARK — PHASE 2-5 MY SPARK 성장경험 실서비스 적용 사전설계 v1.0

기준 운영 버전: **PHASE 2-3.1 · v2.3.1**

목표: 현재 정상 동작 중인 MY SPARK를 유지하면서, 실제 회원이 자신의 성장과 5대 불꽃·MISSION·배지를 한눈에 이해하고 다시 현실 행동으로 나가고 싶게 만드는 화면으로 발전시킨다.

## 1. 이번 단계의 성공 기준

회원 한 명의 MY SPARK를 열었을 때 다음 질문에 5초 안에 답할 수 있어야 한다.

1. 나는 지금 어떤 단계인가?
2. 내 SPARK는 얼마나 성장했는가?
3. 5대 불꽃 중 어떤 불꽃을 많이 키웠는가?
4. 다음에 무엇을 하면 좋은가?
5. 최근 어떤 현실 행동을 했는가?
6. 현재 참여할 MISSION은 무엇인가?

## 2. 화면 우선순위

상단은 아래 순서로 구성한다.

### A. 나의 SPARK HERO 영역

- 회원 이름
- 현재 LEVEL
- 누적 XP
- 현재 대표 성장 캐릭터
- 다음 성장까지 남은 XP
- 짧은 성장 메시지

### B. 5대 불꽃 영역

GOOD / SAFE / EARTH / CHALLENGE / CITIZEN의 현재 활동 분포를 실제 데이터로 표시한다.

현재 구조처럼 최근 활동 20건만 세어 장기 누적처럼 보이지 않도록 한다. v1에서는 ‘최근 활동 기준’임을 명확히 표시하고, 향후 누적 통계 RPC가 필요하면 별도 단계에서 추가한다.

### C. MISSION 영역

- 공개 MISSION
- 완료 여부
- 안전 안내
- 센터 확인 여부

현재 PHASE 2-3 원칙대로 MISSION 완료 자체에는 추가 XP를 지급하지 않는다.

### D. 최근 성장기록

- 활동명
- 대표 불꽃
- XP
- 시간

### E. 다음 현실 행동

화면 체류를 늘리는 대신 현실 행동을 제안한다.

예: “오늘 SAFE 불꽃을 깨울 수 있는 안전한 행동을 하나 찾아보세요.”

## 3. 7단계 캐릭터 연결 방식

PHASE 2-4에서 확정한 캐릭터 7단계를 UI에 사용할 준비를 한다.

중요: 현재 LEVEL 정책은 그대로 유지한다. 캐릭터 7단계는 별도 시각적 구간으로 계산한다.

초기 제안 구간:

- Stage 1: 0–24 XP
- Stage 2: 25–49 XP
- Stage 3: 50–99 XP
- Stage 4: 100–199 XP
- Stage 5: 200–399 XP
- Stage 6: 400–699 XP
- Stage 7: 700 XP 이상

이 값은 운영 실증용 제안값이며, 데이터 분포 확인 후 조정 가능하도록 `spark-growth-config.js` 한 곳에서 관리한다.

## 4. 배지 v1 원칙

현재 배지는 DB 테이블을 새로 만들지 않고 계산형 표시로 시작한다.

예:

- 첫 SPARK: 누적 XP 5 이상
- 꾸준한 시작: 25 이상
- 성장 중: 50 이상
- LEVEL UP: 100 이상

PHASE 2-5에서는 실제 획득 자산 저장·인벤토리를 만들지 않는다. 아이가 재미를 느끼는 시각적 보상만 제공하고, 공식 배지 정책은 이후 별도 테이블 도입 전 확정한다.

## 6. DB 최소화 원칙

PHASE 2-5 기본 UI 적용에는 새 DB 테이블을 만들지 않는다.

기존 summary / recent / mission 데이터를 재사용한다. 장기 5대 불꽃 누적 통계가 실제로 필요할 때만 작은 집계 RPC를 별도로 검토한다.

## 7. 성능 원칙

- 첫 화면에서 회원 전체 데이터를 다시 불러오지 않음
- 현재 선택 회원 데이터만 조회
- 캐릭터·불꽃 자산은 정적 파일
- 애니메이션은 CSS 중심
- 대용량 동영상 금지
- 사운드는 사용자가 행동을 완료했을 때만 선택적으로 재생하는 구조를 추후 검토

## 8. 모바일 UX

MY SPARK는 어린이와 부모가 휴대폰으로 보는 것을 우선한다.

모바일 첫 화면에 다음이 스크롤 전 또는 짧은 스크롤 안에 보여야 한다.

- 이름
- 캐릭터
- LEVEL
- XP
- 다음 성장
- 현재 MISSION 또는 다음 현실 행동

5대 불꽃과 최근 기록은 그 아래로 배치한다.

## 9. 회원 본인 진입과의 관계

현재 69명 회원은 개인 로그인 기능이 없다.

현재 진입:
센터 지도자 로그인 → 회원 선택 → MY SPARK

부모:
부모 공유링크 → 안전한 조회

PHASE 2-5에서는 MY SPARK 화면 경험을 먼저 완성한다. 개인회원 독립 로그인은 다음 별도 PHASE에서 진행한다.
