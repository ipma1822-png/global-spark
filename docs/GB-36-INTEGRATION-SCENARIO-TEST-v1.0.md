# GLOBAL SPARK · GB-36 · 실제 운영 시나리오 통합시험

버전: v3.52.0

## 목적
GB-01~GB-35에서 구축한 성장기지 운영 전 과정을 실제 RPC 흐름으로 연결 시험한다.

시험 흐름:
`신청 → HQ 승인 → 공식번호 → 인증서 → 대표자 연결 → 회원등록 → 아이링크 → 활동 제출 → 센터 승인 → LEVEL 저장 → 온보딩 위험감지 → 지원업무 생성 → 지원업무 완료 → 운영건강도 회복 → 모바일 HOME 확인`

## 안전 원칙
- 실제 운영 데이터에 테스트 성장기지/회원/업무를 남기지 않는다.
- 테스트 DML은 PL/pgSQL 예외 서브트랜잭션으로 전부 롤백한다.
- 공식번호·센터코드·인증서번호·회원번호 시퀀스 상태도 시험 전 값으로 복원한다.
- 테스트 종료 후 전용 테스트 함수는 제거한다.

## 통합시험 중 발견·수정한 실제 회귀 오류

### 1. GB-23 HQ 온보딩 관제 컬럼명 불일치
`spark_hq_onboarding_watch()`가 존재하지 않는 `spark_center_onboarding.approval_center_confirmed`를 참조하고 있었다.
실제 컬럼 `approval_center_ready`로 수정했다.

### 2. GB-18 운영건강도 업무 완료상태 불일치
`spark_internal.center_health_rows()`가 운영업무 완료상태를 `completed`로 계산하고 있었다.
실제 표준 상태는 `done`이므로 완료건수·기한내 완료·미완료 기한초과 계산을 `done` 기준으로 수정했다.

### 3. GB-33 모바일 HOME 온보딩 진행률 타입 오류
`spark_center_mobile_home()`이 `onboarding.progress`를 정수로 직접 캐스팅했다.
실제 `progress`는 `{done,total,percent}` JSON 객체이므로 `progress.percent`를 사용하도록 수정했다.
공식 성장기지가 생겼을 때 모바일 HOME이 실패할 수 있는 오류였다.
