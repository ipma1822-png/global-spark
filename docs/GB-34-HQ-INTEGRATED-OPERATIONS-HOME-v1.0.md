# GB-34 — HQ 통합 운영 HOME 최종판

Version: v3.50.0

## 목적
GLOBAL SPARK HQ가 신청·공식지정·온보딩·위험감지·지원업무·관리자성과·운영건강도·재인증·포상·캠페인·보고서·WORLD NETWORK를 하나의 운영 HOME에서 지휘한다.

## 핵심 구현
- 신규 HQ 전용 RPC: `spark_hq_integrated_operations_home()`
- 기존 `spark_role_command_center()`는 유지하여 HQ/국가/지역 공통 운영화면의 회귀를 방지한다.
- HQ 로그인일 때만 추가 본부 HOME 영역을 표시한다.
- 본부 요약지표: 전체/공식 성장기지, 신청대기, 온보딩 신호, 지원업무, 알림, 운영업무, 기한초과, 재인증, 포상후보, 진행 캠페인, 오늘 생성 보고서.
- HQ 우선처리 큐: 신청, 온보딩 위험, 운영업무를 우선순위로 통합한다.
- 12개 핵심 운영 모듈 바로가기 제공.

## 권한
- anon 실행 차단.
- authenticated에 RPC 실행권한을 주되 함수 내부에서 `spark_is_hq_admin()`을 다시 검사한다.
- 국가/지역 관리자는 기존 공통 COMMAND CENTER만 사용하고 HQ 전용 종합정보에는 접근하지 못한다.

## 검증
- 실제 HQ 권한 컨텍스트에서 트랜잭션 기반 호출 검증 완료.
- 검증 시점 실데이터: 운영 성장기지 1, 공식 성장기지 0, 미해결 알림 1, 진행 캠페인 1, 진행 업무 0.
- 계명태권도 KMT-000001은 `unassigned` 상태 유지.
- 가짜 공식 성장기지나 운영데이터를 생성하지 않음.
