# GS-07 — 성장기지 개설 마법사

- 운영 버전: v3.59.0
- 목적: HQ 승인 및 대표자 연결 후 공식 성장기지가 5~10분 안에 운영 준비를 시작하도록 기존 온보딩 기능을 하나의 순서형 화면으로 연결한다.

## 구현
- `growth-base-setup.html` 신규
- 로그인 후 `spark_get_my_centers()`로 본인 성장기지 선택
- 공식 성장기지만 `spark_center_onboarding_status()`로 7단계 준비상태 표시
- 기존 자동 완료 데이터와 수동 확인 항목을 그대로 사용
- 마지막에 `center-mobile-home.html?center=...`로 실제 운영 시작
- `my-centers.html`에 개설 마법사 진입 추가

## 보호 원칙
- 새로운 온보딩 DB를 만들지 않는다.
- GB-22의 `spark_center_onboarding` 및 기존 RPC를 재사용한다.
- HQ 승인/공식번호/인증서/회원/활동/LEVEL 로직을 변경하지 않는다.
- `KMT-000001`은 실제 `unassigned` 성장기지이므로 공식 개설 테스트 대상으로 변경하지 않는다.
- 공식 지정이 아닌 성장기지는 마법사에서 온보딩할 수 없다.

## 운영 흐름
HQ 승인 → 대표자 연결 → 로그인 → 내 성장기지 선택 → 기존 7단계 온보딩 → 모바일 HOME → 첫 운영
