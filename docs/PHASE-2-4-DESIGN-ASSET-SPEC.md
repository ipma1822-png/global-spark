# GLOBAL SPARK — PHASE 2-4 공식 디자인 자산 기준 v1.0

기준 운영 버전: **PHASE 2-3.1 · v2.3.1**

이 문서는 지금까지 제작한 디자인 시안의 반복 생산을 종료하고, 실제 서비스에 사용할 공식 디자인 자산의 규격과 교체 원칙을 확정하기 위한 기준서다.

## 1. 핵심 원칙

- 디자인 시안 전체 이미지를 홈페이지에 통째로 넣지 않는다.
- 이미지 속 가상 회원 수, 가상 랭킹, 가상 XP, 가상 센터명·국가 수치는 실제 서비스에 사용하지 않는다.
- 서비스 문구와 수치는 HTML/JS에서 실제 데이터로 표시한다.
- 캐릭터·배지·아이콘은 독립 파일로 관리한다.
- 이미지 파일을 교체해도 DB·XP·MISSION·회원 로직을 수정할 필요가 없어야 한다.
- 서버는 계산하고 화면은 연출한다.
- 모바일에서 빠르게 보이도록 작은 용량과 단순한 파일 구조를 우선한다.

## 2. 공식 비주얼 방향

대표 스타일은 다음으로 확정한다.

- 밝고 친근한 불꽃 마스코트
- 게임처럼 화려하지만 어린이 교육·공익운동의 신뢰감을 유지
- 기본 배경은 짙은 네이비 계열, 성장·보상은 불꽃·골드·네온 효과
- 둥글고 읽기 쉬운 카드 UI
- 작은 화면에서도 캐릭터 실루엣과 불꽃 색상이 즉시 구분되어야 함
- 과도한 텍스트를 이미지에 직접 넣지 않음

## 3. 대표 SPARK 성장 7단계

향후 공식 캐릭터 자산은 아래 7단계를 사용한다.

1. **불씨 / SPARK SEED** — 시작의 불꽃
2. **초롱이 / LITTLE SPARK** — 관찰과 배려를 배우는 단계
3. **열린이 / OPEN SPARK** — 행동과 도전을 시작하는 단계
4. **스파키 / SPARKY** — 배우고 익히며 성장하는 단계
5. **파이터 / SPARK FIGHTER** — 함께 행동하며 책임을 배우는 단계
6. **히어로 / SPARK HERO** — 공동체를 지키고 돕는 단계
7. **글로벌 리더 / GLOBAL LEADER** — 세계와 함께 더 큰 빛을 나누는 단계

중요: 이 7단계는 캐릭터 성장 연출 기준이며, 현재 LEVEL 계산식(100 XP 단위)을 즉시 변경한다는 뜻이 아니다. LEVEL 정책과 캐릭터 성장단계의 연결 규칙은 별도 정책으로 확정한다.

## 4. 5대 불꽃 공식 심볼

- GOOD — 선한 불꽃 — 하트 계열
- SAFE — 안전 불꽃 — 방패 계열
- EARTH — 환경 불꽃 — 잎/지구 계열
- CHALLENGE — 도전 불꽃 — 산/별/도전 계열
- CITIZEN — 시민 불꽃 — 사람/공동체 계열

현재 `assets/spark/flames/` 구조를 그대로 유지하며 공식 이미지 완성 시 경로만 교체한다.

## 5. 레벨·성장 배지

초기 공식 배지 계열:

- STARTER
- CHALLENGER
- GUARDIAN
- STAR
- HERO
- LEGEND
- GLOBAL HERO

배지는 장식적 보상이며 실제 XP 원장과 별도다. 획득 조건을 DB에 추가하기 전 운영정책을 먼저 확정한다.

## 6. 전문 성장 영역 배지

GLOBAL SPARK의 전문기관 연결 자산으로 다음 네 영역을 우선 사용한다.

- 태권도 / TAEKWONDO
- 태권검도 / TKD SWORD
- 드론순찰 / DRONE PATROL
- 경찰무도 / POLICE MARTIAL

전문영역은 일반 SPARK 회원에게 위험한 장비 사용을 권장하는 시스템이 아니다. 안전·법규·연령·지도자 조건이 필요한 전문 교육은 일반 MISSION과 분리한다.

## 7. 공식 자산 폴더 권장 구조

```text
assets/spark/
  characters/
    stage-01.webp
    stage-02.webp
    stage-03.webp
    stage-04.webp
    stage-05.webp
    stage-06.webp
    stage-07.webp
  flames/
    good.webp
    safe.webp
    earth.webp
    challenge.webp
    citizen.webp
  badges/
    levels/
    flames/
    specialties/
    missions/
  items/
  effects/
  ui/
```

현재 존재하는 SVG는 공식 최종 자산이 준비될 때까지 임시 자산으로 유지한다.

## 8. 파일 규격

- 캐릭터: 투명배경 WebP 우선, 필요 시 PNG 원본 보관
- 아이콘·배지: WebP 또는 SVG
- 효과: CSS 우선, 필요한 경우 소형 WebP/PNG
- 모바일 표시용 캐릭터 권장 크기: 512×512 이하
- 아이콘 권장 크기: 128×128 이하
- 대용량 배경 영상은 기본 UI 자산으로 사용하지 않음

## 9. 교체 원칙

공식 자산 교체 시 우선 `assets/js/spark-growth-config.js`의 자산 경로만 변경한다.

핵심 비즈니스 로직, Supabase 테이블, KMT Connector, XP, UNDO, MISSION RPC를 이미지 교체 때문에 수정하지 않는다.

## 10. 지금 하지 않는 것

- 이미지 시안 추가 반복 생산
- 캐릭터 거래
- 유료 아이템
- 복잡한 인벤토리
- 실제 랭킹 보상 DB
- 캐릭터 성장에 따른 XP 공식 변경
- 전문 무기·장비를 일반 어린이 MISSION으로 연결

## 11. 완료 기준

PHASE 2-4 디자인 작업은 다음이 명확하면 완료로 본다.

- 대표 캐릭터 7단계
- 5대 불꽃 심볼
- 레벨 배지 계열
- 전문 성장 4영역
- 교체 가능한 파일 규격과 폴더 구조
- 실제 서비스 숫자는 DB에서만 표시

이후 디자인 작업은 필요한 공식 개별 자산을 제작할 때만 진행한다.
