# GLOBAL SPARK — GB-20 역할별 통합 COMMAND CENTER v1.0

Version: GB-20 · v3.36.0

## 목적
GB-10~GB-19에서 구축한 국가·지역 관제, 일일 브리핑, 운영알림, 운영업무, 운영건강도, 개선계획을 역할별 하나의 운영 HOME으로 통합한다.

## 신규 RPC
`public.spark_role_command_center()`

- 로그인 필수.
- HQ는 전체 세계 범위.
- 국가관리자는 지정 국가 범위.
- 지역관리자는 지정 지역 범위.
- 기존 권한형 RPC를 재사용하여 별도의 우회 권한을 만들지 않는다.
- anon/PUBLIC 실행권한을 회수하고 authenticated에만 EXECUTE를 부여한다.
- 어린이 이름·사진·전화번호·정밀 위치를 반환하지 않는다.

통합 정보:
- 담당 국가·성장기지·활성회원·7일 활동
- 승인대기
- 미해결/긴급 운영알림
- 대기/진행/기한초과 운영업무
- 운영건강도 우수/건강/관찰/위험
- 우선 확인 성장기지
- 일일 운영 브리핑

## 화면
`command-center.html`

한 화면에서 현재 운영상태를 확인하고 다음 기존 전문 화면으로 이동한다.

- 일일 브리핑
- 운영알림센터
- 운영업무
- 성장기지 운영건강도
- 30일 개선계획
- 국가·지역 관제
- 성장분석
- 네트워크 관리자 체계

`network-command.html`에는 통합 COMMAND CENTER 진입 버튼을 추가하고 버전을 GB-20 v3.36.0으로 갱신했다.

## 실제 검증
HQ 인증 컨텍스트에서 `spark_role_command_center()` 호출 성공.
검증 당시 실제 운영값:
- 국가 1
- 성장기지 1
- 활성회원 69
- 최근 7일 활동 57
- 승인대기 0
- 미해결 운영알림 1
- 긴급 알림 0
- 운영건강도 관찰 1
- 계명태권도 운영건강도 62점
- 현재 운영업무 0

계명태권도는 `designation_status` 기준 공식 지정 성장기지가 아니므로 COMMAND CENTER에서도 공식 성장기지로 표시하거나 간주하지 않는다.

## 보존 원칙
기존 GB-10~GB-19 RPC/화면/업무흐름을 재개발하지 않고 통합 조회 및 이동 허브만 추가했다. 사이트 배포는 별도 수행하지 않았다.
