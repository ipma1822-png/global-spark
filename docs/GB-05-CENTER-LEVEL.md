# GLOBAL SPARK · GB-05 — 성장기지 LEVEL·운영평가·성장분석

버전: v3.21.0

## 목적
성장기지의 회원 수나 누적 SPARK 총량이 아니라 최근 운영의 질을 평가한다. 작은 센터도 참여율과 꾸준함, 5대 불꽃의 균형, 다양한 성장경험, 공식 캠페인 참여가 좋으면 높은 LEVEL을 받을 수 있다.

## 100점 평가식
- 참여율: 35점 — 최근 30일 활동회원 / 현재 활동회원
- 꾸준함: 20점 — 최근 최대 8주 동안 활동이 이어진 주의 비율. 신규 성장기지는 실제 운영기간만 분모로 사용
- 5대 불꽃 균형: 20점 — GOOD, SAFE, EARTH, CHALLENGE, CITIZEN의 영역 커버리지와 분포 균형
- 활동 다양성: 15점 — 최근 30일 서로 다른 성장경험 종류
- 캠페인 참여: 10점 — 최근 공식 캠페인 참여회원 비율. 평가기간에 공식 캠페인 자체가 없으면 센터에 불이익을 주지 않음

## LEVEL
1. 0~24: 새싹 성장기지
2. 25~39: 불꽃 성장기지
3. 40~54: 성장기지
4. 55~69: 우수 성장기지
5. 70~84: 명예 성장기지
6. 85~94: 글로벌 성장기지
7. 95~100: MASTER 성장기지

## 구현
- Supabase RPC: `spark_center_level_analysis(p_center_code text)`
- 인증된 성장기지 STAFF만 실행 가능
- 익명 실행 권한 없음
- `SECURITY DEFINER` 사용 시 `search_path=''` 고정
- 기존 SPARK/XP/승인/일괄등록 구조는 변경하지 않음
- 화면: `center-level.html?center=<CENTER_CODE>`
- MY SPARK CENTER에서 `🏅 LEVEL · 운영평가` 버튼으로 진입

## 현재 평가 예시
실데이터 검증 시 계명태권도 성장기지는 51점, LEVEL 3 `성장기지`로 계산되었다. 이 값은 운영 데이터가 변하면 자동으로 다시 계산된다.
