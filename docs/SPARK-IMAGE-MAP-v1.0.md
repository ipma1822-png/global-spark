# GLOBAL SPARK IMAGE MAP v1.0

## 목적

`assets/spark/banners/`에 업로드된 26장의 WebP 이미지를 실제 비주얼 기준으로 B(페이지 대표 배너)와 V(공용 비주얼)로 논리 분류한다.

- B = 특정 페이지/기능의 대표 배너
- V = 여러 페이지에서 재사용 가능한 공용 비주얼
- 기존 바이너리 파일명은 당장 변경하지 않는다.
- 코드에서는 `assets/js/spark-image-map.js`의 `window.SPARK_IMAGE_MAP.Bxx / Vxx` 별칭을 사용한다.
- 이미지 안에 이미 들어간 작은 관리번호가 실제 논리번호와 다른 경우, 파일 내부 표식보다 이 문서와 JS 맵을 우선한다.

## 표시 원칙

1. 이미지 자체는 설명문 역할을 하지 않는다. 긴 제목·문장·수치·메뉴는 HTML로 표시한다.
2. 배너는 기본적으로 `object-fit: cover`를 사용하되 인물과 핵심 피사체가 잘리지 않도록 `object-position`을 페이지별 조정한다.
3. PC에서는 넓은 시네마틱 비율, 모바일에서는 핵심 피사체 중심 크롭을 사용한다.
4. 권장 효과는 매우 약한 slow zoom, glow pulse, particle/light drift, network shimmer 수준으로 제한한다.
5. 같은 페이지에서 B이미지를 주인공으로 쓰고 V이미지는 보조 섹션에서만 사용한다.
6. 지나치게 텍스트가 많은 이미지(V10 등)는 대표 히어로보다 보조 섹션에서 우선 사용한다.
7. B/V 번호는 앞으로 코드와 문서에서 고정 식별자로 사용한다.

## 코드 사용 예

```html
<script src="assets/js/spark-image-map.js"></script>
<script>
  document.querySelector('#hero').src = window.SPARK_IMAGE_MAP.B03;
</script>
```
