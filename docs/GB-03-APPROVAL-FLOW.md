# GLOBAL SPARK 공식지정 성장기지 · GB-03

## 목표
아이·부모가 직접 기록한 성장행동을 즉시 XP로 확정하지 않고, 성장기지의 확인을 거쳐 공식 SPARK로 인정한다.

## 흐름
1. 아이 또는 부모가 개인 SPARK 링크에서 행동을 선택하고 메모를 작성한다.
2. `spark_activity_submissions`에 `pending` 상태로 저장한다.
3. 성장기지 지도자는 `center-approvals.html?center=센터코드`에서 승인대기 목록을 확인한다.
4. 승인 시 `spark_activities`와 `spark_ledger`에 공식 기록을 생성한다.
5. 거절 시 XP는 생성하지 않고 제출 기록만 `rejected`로 보존한다.

## 보안
- 제출은 유효한 개인 링크 토큰이 있어야 한다.
- 승인대기 목록 조회 및 승인/거절은 해당 성장기지 STAFF만 가능하다.
- 익명 사용자는 승인목록 조회나 승인 RPC를 실행할 수 없다.
- RLS를 활성화하고 STAFF/HQ 조회 정책을 적용한다.

## 운영 원칙
- 기존 센터 직접입력 기능은 유지한다.
- 기존 활동/원장 데이터를 변경하지 않는다.
- 아이 직접기록은 이제 승인대기 방식이 기본이다.
- 부모 기록은 동일 개인링크에 `?as=parent`를 붙이면 부모 제출로 구분된다.
