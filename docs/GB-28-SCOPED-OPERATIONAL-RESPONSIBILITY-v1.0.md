# GB-28 — 국가·지역 관리자 운영책임 강화

버전: v3.44.0

## 목적
HQ가 모든 성장기지를 직접 관리하는 구조에서 벗어나 국가관리자와 지역관리자가 자기 책임권역의 온보딩, 위험신호, 운영업무, 운영건강도, 정기평가를 한 화면에서 관리하도록 한다.

## 권한범위
- HQ: 전체 성장기지
- country_admin: 지정 국가 전체
- region_admin: 지정 국가 + 지정 지역
- 권한 없는 authenticated 사용자는 차단
- anon 실행 차단

## 신규 RPC
### `spark_scoped_operational_responsibility()`
현재 로그인 관리자의 책임권역을 계산하고 다음을 반환한다.
- 성장기지 수 / 공식 성장기지 수
- 주의 필요 성장기지 수
- 미해결 알림 수
- 진행중 운영업무 / 기한초과 업무
- 온보딩 위험신호
- 성장기지별 운영건강도
- 정기평가 및 재인증 상태
- 최근 7일 활동량 / 활성회원 수

### `spark_network_responsibility_note(center_code,note,action)`
권역 관리자가 담당 성장기지에 운영 메모를 남길 수 있는 기반 RPC. 자기 권역 외 성장기지는 차단한다.

## 신규 테이블
`public.spark_network_responsibility_notes`
- 운영 책임 메모 저장
- RLS 활성화
- direct table access 차단
- RPC 전용

## UI
`network-operations.html`
- GB-28 v3.44.0 표시
- 역할/책임범위 표시
- 책임권역 요약 카드
- 우선 지원 성장기지 목록
- 건강도/알림/업무/온보딩 바로가기

## 기존 기능 보호
- GB-10 네트워크 권한구조 유지
- GB-22 온보딩 유지
- GB-23/24 위험신호·지원업무 유지
- GB-26 정기평가·재인증 유지
- GB-27 수명주기 HQ 전용 권한 유지
- 국가/지역 관리자는 공식지정 취소·정지·복원 권한을 얻지 않는다.

## 데이터 원칙
- 미성년자 이름, 사진, 연락처를 권역 운영대시보드에 노출하지 않는다.
- 집계·운영 상태만 표시한다.
- 테스트용 가짜 관리자, 성장기지, 메모를 영구 저장하지 않는다.
