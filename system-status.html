성장 엔진 · PHASE 3 기준

누적 XP는 공식 원장 기준으로 계산하며 LEVEL 정책과 7단계 시각 성장경험은 기존 기준을 유지합니다. 5대 불꽃은 최근 행동의 균형을 보여주는 성장지표로 사용하며, 환경 불꽃(EARTH)의 「환경보호·절약」 공식 활동도 운영합니다.

SPARK MISSION v1.0

HQ가 5대 불꽃 MISSION을 만들고 공개할 수 있습니다. 회원은 MY SPARK에서 확인하고 현실 행동 후 센터 지도자가 완료를 확인합니다. MISSION 완료 자체에는 현재 별도 XP를 지급하지 않습니다.

아이 직접 참여 · PHASE 3-2

센터 지도자는 회원카드에서 아이 전용 SPARK 링크를 발급하고 바로 복사할 수 있습니다. 새 링크를 다시 발급하면 기존 링크는 자동 무효화되며, 「해제」를 누르면 현재 개인링크 사용이 즉시 중지됩니다. 아이는 별도 로그인 없이 해당 링크로 SPARK WORLD에 들어가 자신의 좋은 행동을 직접 기록할 수 있습니다.

센터 운영 원칙

센터는 모든 행동을 일일이 사전 승인하는 구조가 아니라, 아이의 성장 흐름을 확인하고 이상 기록을 정정하는 성장관리 거점으로 운영합니다.

KMT CLASS 연동

계명태권도 제1호 어린이·청소년 실증센터의 승인된 STAR는 기존 연동방식을 유지하며 GLOBAL SPARK 활동과 공식 XP 체계를 보호합니다.

다음 PHASE

PHASE 3-3에서는 센터가 많은 아이를 효율적으로 관리하도록 오늘 활동·최근 7일·미활동·LEVEL 상승·불꽃 균형·이상 기록을 한눈에 보는 성장관리판을 구축합니다. 기존 XP·회원·센터·HQ·MISSION·LIVE·Supabase 구조는 재개발하지 않습니다.
